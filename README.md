# Career-Connect

Career-Connect is a responsive frontend application for job seekers and recruiters. It shows job listings, lets users track their applications, and displays company profiles. The frontend fetches its data from backend APIs.

> **Scope:** This repository contains the **frontend only**.
> **Showcase:** [https://connect-the-career.netlify.app/]

## Features

- **Job listing module:** browse job offers fetched from the backend API.
- **Application tracking module:** track the status of job applications.
- **Company profile module:** view details about companies.
- **Reusable UI components:** shared components used across the modules.
- **Responsive design:** works on desktop and mobile screens.
- **API integration:** the frontend interfaces are integrated with backend APIs.

## Tech stack

- **Frontend:** [HTML, CSS, JavaScript]
- **Data:** REST APIs (fetched from the frontend)
- **Backend:** not part of this repository


**Plain HTML/CSS/JS:**
Open `index.html` in a browser, or serve the folder with a local server (for example the VS Code "Live Server" extension).
